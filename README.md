# Infant Radiant Warmer Repair Trainer

สื่อฝึกซ่อมและบำรุงรักษาเครื่องอุ่นทารกแบบแผ่รังสี (infant radiant warmer) ของศูนย์การเรียนรู้เทคโนโลยีทางการแพทย์
เครื่องในแอปเป็นเครื่องจำลองทั่วไป เนื้อหาเขียนใหม่จากหลักการในคู่มือผู้ใช้และคู่มือซ่อมของเครื่องหลายรุ่น (GE Panda iRes, Fisher & Paykel 900 Series, Panda/Giraffe Service Manual) ไม่ได้คัดลอกภาพหรือตาราง

ใน repo นี้จะมี 3 วิชา (ทำทีละวิชา)
- `/` วิชาช่างเครื่องอุ่นทารก (แอป `warmer` เลขที่ `IWT-`) ← พร้อมแล้ว
- `/phototherapy/` วิชาช่างเครื่องส่องไฟรักษาตัวเหลือง (ฉบับสั้น) ← ยังไม่ทำ
- `/clinical/` วิชาคลินิกรวมสองเครื่อง สำหรับพยาบาล ← ยังไม่ทำ

## โมดูล (เรียนตามลำดับ สอบท้ายโมดูลสุ่ม 5 จาก 8 ข้อ ผ่าน 4 ข้อ)

1. ภาพรวมการทำงาน – วงรอบการควบคุมแบบเซอร์โว 4 ระบบ 3 โหมด เทียบกับตู้อบ
2. ส่วนประกอบ – แตะชิ้นส่วนบนภาพ 10 ชิ้น
3. การใช้งานสำหรับช่าง – บทเรียน ฝึกตั้งเครื่อง ตรวจก่อนใช้ มุมช่าง (`clin:sim`)
4. ด่านความปลอดภัย – สอบท้ายโมดูลต้องถูกครบ 5 ข้อ (`pass:5` ใน data/mquiz.js, `mqPass` ใน config และ Code.gs)
5. ตรวจรับเครื่อง (`accept`)
6. PM ตามรอบ (`pmplan`)
7. คู่มือวิเคราะห์อาการ + โจทย์ซ่อม 10 เคส โหมดเรียนรู้ (`learn:`) และโหมดสอบ (`exam:`)
8. ทดสอบหลังซ่อม (ฝึกตัดสินผล 7 หัวข้อ) + ลำดับขั้นตอนงาน 3 งาน (`order:`)
- สอบรวม 20 ข้อ (`quiz`) เปิดเมื่อผ่านครบ 8 โมดูล
- หน้า 3D (`3d/`) – Three.js ดูรังสีความร้อนตกบนเตียง ฝึกถอดเปลี่ยน 6 งาน (ไม่นับเกณฑ์)

## โครงสร้างไฟล์

```
index.html          โครงหน้า
css/warmer.css      ภาพเครื่องอุ่นทารกและส่วนที่ต่างจากวิชาอื่น (style.css, svc.css ใช้ร่วมกับวิชาอื่น)
js/dia.js           ภาพเครื่องอุ่นทารก (SVG, WMDIA) ใช้ร่วมกันทุกโมดูล
js/app.js           โมดูล 1–2, 4, 7 (คู่มืออาการ) และการเปลี่ยนหน้า
js/learn.js         โหมดเรียนรู้ (ภาพเคลื่อนไหว ภาพขยาย)   js/sim.js  โหมดสอบ
js/tech.js          โมดูล 3   js/svc.js โมดูล 5–6   js/pm.js, js/order.js โมดูล 8   js/quiz.js สอบรวม
js/score.js, auth.js, cert.js, mgate.js   ระบบบัญชี คะแนน เกียรติบัตร เรียนตามลำดับ (ใช้ร่วมกับวิชาอื่น)
data/*.js           เนื้อหาทั้งหมด แก้ได้โดยไม่ต้องแตะโค้ด
3d/                 หน้า 3 มิติ (main.js โมเดล · data.js ใบงาน · task.js โหมดฝึก)
```

คะแนนเก็บในคีย์ localStorage ขึ้นต้น `iwt-` และส่งเข้า Google Sheet "Med Center" ผ่าน Apps Script ตัวเดียวกับทุกวิชา (แอป `warmer`)
ตัวเลขเกณฑ์และราคาอะไหล่ทั้งหมดเป็นค่าตัวอย่างของเครื่องจำลอง
